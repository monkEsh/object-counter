API reference

How to call POST /object-count directly.

POST http://<host>:5001/object-count multipart/form-data
FieldTypeRequiredDescription
file binary Yes Image file (JPEG, PNG, etc.)
threshold number 0–1 No Confidence threshold. Default 0.5.
model_name string No Public model alias. Default count-current.

curl example

curl -X POST http://127.0.0.1:5001/object-count \
  -F "file=@/path/to/image.jpg" \
  -F "threshold=0.9" \
  -F "model_name=count-current"

Python example

import requests

with open("/path/to/image.jpg", "rb") as f:
    response = requests.post(
        "http://127.0.0.1:5001/object-count",
        files={"file": f},
        data={"threshold": 0.9, "model_name": "count-current"},
    )
print(response.json())
